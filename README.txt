ORGANIVA WEBSITE
================
1. To take real orders: open index.html in a text editor, search for
   "ORGANIVA LIVE ORDERS" and paste your Supabase Project URL and
   PUBLISHABLE key between the quotes. Never paste the secret key.
2. Upload this whole folder to any static host (for example
   https://app.netlify.com/drop - drag the folder onto the page).
3. Database setup and WhatsApp alerts: follow the guide
   "Organiva: live orders setup (Supabase + WhatsApp)".
With the two values left empty, the site runs on built-in demo data.
